# IPAS AI 應用規劃師 - 學習翻卡系統

**線上使用：** https://ipas-flashcards.emoyilab.com

針對經濟部 IPAS「AI 應用規劃師」能力鑑定，打造的互動式學習工具。

## 為什麼做這個？

IPAS AI 應用規劃師的考試範圍很廣，從機器學習、深度學習、NLP、電腦視覺到大數據處理都有。光看課本 PDF 很難記住幾百個專有名詞和概念之間的差異。

這個工具用**翻卡記憶法**解決這個問題——正面只有名詞，先自己回想，翻面看完整解釋。每張卡都用口語化的方式寫，搭配具體範例，讓完全不懂的人也看得懂。

### 考題在考什麼？

分析了 393 題歷屆考題與模擬題後發現，**純背定義的題目只占約 24%**，其餘 76% 都需要更深層的理解：

| 題型 | 占比 | 說明 |
|---|---|---|
| 概念與定義 | ~24% | 這個名詞是什麼意思 |
| 技術比較 | ~20% | A 和 B 差在哪裡、什麼時候選哪個 |
| 應用與解題 | ~28% | 給一個情境，選最適合的技術方案 |
| 計算題 | ~11% | Z-Score、Gini 不純度等公式計算 |
| 情境與商業 | ~13% | 企業要導入 AI，該怎麼規劃 |
| 批判分析 | ~4% | 某技術在什麼情況下會失敗 |

所以光背名詞定義是不夠的，考試更重視「什麼時候用」「跟別的差在哪」「會有什麼風險」。這也是為什麼每張卡片的背面不只寫定義，還包含了**使用時機、優缺點比較、容易搞混的地方、考試常見考法**——直接對應考題最常出的題型。

## 功能

**學習卡片（290+ 張）**
- 初級：人工智慧基礎概論（8 主題，約 149 張）
- 中級科目一：AI 技術應用與規劃（8 主題，約 101 張）
- 中級科目二：大數據處理分析與應用（5 主題，約 41 張）
- 支援「全部隨機」洗牌模式，打散主題交叉複習
- 卡片目錄側邊欄，快速跳轉到特定名詞

**歷屆考題練習（393 題）**
- 單題模式：隨機抽 15 題，做一題看一題解析
- 整卷模式：隨機抽 15 題，做完再一起檢討
- 全部檢視：按順序做完全部題目，支援暫停/繼續（進度自動儲存）

**AI 語音朗讀**

為什麼要加朗讀功能？根據認知心理學的**雙重編碼理論（Dual Coding Theory）**，人類同時透過視覺和聽覺接收資訊時，大腦會建立兩條獨立的記憶路徑，記憶效果顯著優於只用單一感官。此外，**多感官學習（Multisensory Learning）** 研究也指出，邊看邊聽能提升專注力並加深理解，特別適合需要記住大量專有名詞的考試準備。

- 使用微軟 Edge TTS 神經網路語音合成，而非裝置內建的機械式語音
- AI 合成的語調自然、斷句流暢，長時間聽也不會疲勞，適合邊聽邊複習
- 所有平台（iPhone、Android、桌機）聽到的都是同樣品質的聲音，不受裝置限制
- 可選 6 個中文語音 + 4 個英文語音，語速可調
- 首次朗讀需約 1-2 秒合成，同一張卡第二次點擊秒播（已快取）

## 技術

- **前端：** Vue 3（Composition API）+ Vite
- **語音：** 微軟 Edge TTS，透過 Vercel Serverless Function 代理
- **部署：** Vercel（GitHub 推送後自動部署）
- **圖表：** Chart.js + vue-chartjs

## 本地開發

```bash
cd flashcards
npm install
npm run dev
# 開啟 http://localhost:5211
```

> 語音功能需要 Vercel 的 `/api/tts` 端點，本地開發時語音朗讀不可用，需部署到 Vercel 或自行架設 TTS 代理。

## 一起貢獻卡片

歡迎任何人幫忙新增學習卡片或考題！你不需要會寫程式，只要有課本內容或考題，搭配 Claude 就能自動產出符合格式的卡片。

### 事前準備

1. Fork 這個 repo 到你自己的 GitHub 帳號
2. Clone 到本地：`git clone https://github.com/你的帳號/IPAS-AI-Application-Planner.git`
3. 安裝 [Claude Code](https://claude.ai/claude-code)（Anthropic 的 CLI 工具）

### 用 Claude 幫你建卡片

這個專案已經寫好完整的 `CLAUDE.md` 說明文件，裡面包含卡片格式、寫作風格、資料結構、檔案位置等所有規範。當你在專案目錄下啟動 Claude Code，它會自動讀取這些規範，知道該怎麼做。

**你只需要：**

1. 建立你的分支
   ```bash
   git checkout -b add/你的主題名稱
   ```

2. 啟動 Claude Code，把課本內容或考題貼給它
   ```
   claude
   ```

3. 告訴 Claude 你想做什麼，例如：
   - 「這是初級第二科的課本第三章，幫我把重點名詞做成學習卡片」
   - 「這是 113 年的考古題，幫我建成考題檔案，每個選項也做成學習卡」
   - 「幫我在 NLP 主題補一張 BERT 的卡片」

4. Claude 會自動：
   - 依照 `CLAUDE.md` 的卡片格式和寫作規範產出內容
   - 每個選項獨立做成一張卡，用口語化方式解釋
   - 放到正確的檔案位置（`flashcards/src/data/` 下對應的主題）
   - 更新 `cards.js` 的匯入

5. 確認沒問題後，推送並發 Pull Request
   ```bash
   git add .
   git commit -m "[功能] 新增 XXX 卡片"
   git push origin add/你的主題名稱
   ```
   到 GitHub 頁面點「Compare & pull request」，等待審核合併。

### 注意事項

- **請勿直接推送到 main 分支**，一律透過 Pull Request 合併
- 卡片內容要用**繁體中文**，解釋要夠詳細，讓不懂的人也看得懂
- 如果名詞已經有對應的卡片，就不用重複建立
- 有任何問題歡迎開 Issue 討論
