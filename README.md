# IPAS AI 應用規劃師 - 學習翻卡系統

**線上使用：** https://ipas-flashcards.emoyilab.com

針對經濟部 IPAS「AI 應用規劃師」能力鑑定，打造的互動式學習工具。

## 為什麼做這個？

IPAS AI 應用規劃師的考試範圍很廣，從機器學習、深度學習、NLP、電腦視覺到大數據處理都有。光看課本 PDF 很難記住幾百個專有名詞和概念之間的差異。

這個工具用**翻卡記憶法**解決這個問題——正面只有名詞，先自己回想，翻面看完整解釋。每張卡都用口語化的方式寫，搭配具體範例，讓完全不懂的人也看得懂。

## 功能

**學習卡片（290+ 張）**
- 初級：人工智慧基礎概論（8 主題，約 149 張）
- 中級科目一：AI 技術應用與規劃（8 主題，約 101 張）
- 中級科目二：大數據處理分析與應用（5 主題，約 41 張）
- 支援「全部隨機」洗牌模式，打散主題交叉複習
- 卡片目錄側邊欄，快速跳轉到特定名詞

**歷屆考題練習（393 題）**
- 單題模式：隨機抽 15 題，做一題看一題解析
- 整卷模式：隨機抽 15 題，做完再一起檢討
- 全部檢視：按順序做完全部題目，支援暫停/繼續（進度自動儲存）

**AI 語音朗讀**
- 使用微軟 Edge TTS 神經網路語音合成，而非裝置內建的機械式語音
- AI 合成的語調自然、斷句流暢，長時間聽也不會疲勞，適合邊聽邊複習
- 所有平台（iPhone、Android、桌機）聽到的都是同樣品質的聲音，不受裝置限制
- 可選 6 個中文語音 + 4 個英文語音，語速可調
- 首次朗讀需約 1-2 秒合成，同一張卡第二次點擊秒播（已快取）

## 技術

- **前端：** Vue 3（Composition API）+ Vite
- **語音：** 微軟 Edge TTS，透過 Vercel Serverless Function 代理
- **部署：** Vercel（GitHub 推送後自動部署）
- **圖表：** Chart.js + vue-chartjs

## 本地開發

```bash
cd flashcards
npm install
npm run dev
# 開啟 http://localhost:5211
```

> 語音功能需要 Vercel 的 `/api/tts` 端點，本地開發時語音朗讀不可用，需部署到 Vercel 或自行架設 TTS 代理。
